# 💚 Meu Financeiro

Um jeito mais simples e organizado de cuidar do seu dinheiro!

O **Meu Financeiro** é um aplicativo de controle financeiro pessoal desenvolvido para ajudar no acompanhamento de gastos, entradas e organização das finanças. Com uma interface intuitiva e visual moderno, ele permite acompanhar sua vida financeira de forma prática, diretamente pelo celular ou computador.

## ✨ Funcionalidades

- **Visão geral:** acompanhe seu saldo, entradas, gastos e movimentações recentes.
- **Controle de gastos:** registre suas despesas, organize por categorias e mantenha tudo sob controle.
- **Controle de entradas:** registre seus recebimentos e acompanhe o dinheiro que entra.
- **Histórico financeiro:** consulte suas movimentações e acompanhe seus registros.
- **Relatórios:** visualize gráficos, categorias e informações que ajudam a entender seus hábitos financeiros.
- **Personalização:** configure categorias, cores e ícones de acordo com suas preferências.
- **Backup:** exporte e importe seus dados para manter suas informações seguras.

## 🎨 Interface

O aplicativo conta com uma interface responsiva, tema escuro e detalhes em verde, buscando oferecer uma experiência agradável, organizada e fácil de utilizar.

## 🛠️ Tecnologias

- HTML
- CSS
- JavaScript
- PWA (Progressive Web App)
- Armazenamento local do navegador

## 📲 Como acessar e instalar

O Meu Financeiro já está publicado na internet! Isso significa que você não precisa baixar nenhum arquivo ou passar por uma loja de aplicativos para começar a usar.

1. Acesse o aplicativo pelo link: **[COLOQUE AQUI O LINK DO DEPLOY]**
2. Abra pelo navegador do seu celular ou computador.
3. Para instalar no celular, utilize a opção **"Adicionar à tela inicial"** ou **"Instalar aplicativo"**, quando disponível.
4. Pronto! O Meu Financeiro ficará disponível como um aplicativo na tela inicial do seu dispositivo.

## 🔒 Privacidade

As informações financeiras são armazenadas localmente no dispositivo, sem necessidade de criar uma conta. Por isso, é importante realizar backups periódicos para evitar a perda dos dados.
